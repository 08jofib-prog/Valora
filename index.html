Sannolikheten visar hur ofta liknande lägen historiskt följdes av en positiv avkastning över vald horisont. "Edge" är skillnaden mot aktiens egen genomsnittliga träffsannolikhet.

Inställningar

Så fungerar modellen

För varje aktie och dag beräknas tekniska och marknadsrelaterade nyckeltal. Modellen letar sedan upp de historiska dagar som mest liknar dagens läge och mäter vad som hände framåt (forward return).

  1. Features: 5- och 20-dagars momentum, RSI(14), kort/lång volatilitet, avstånd till 50-dagars medelvärde och relativ styrka mot marknaden.
  2. Likhetssökning (k-NN): de 40 mest lika historiska lägena (standardiserade avstånd).
  3. Forward return: andelen grannar med positiv avkastning över 3, 5 eller 10 handelsdagar samt snittavkastning.
  4. Krympning: sannolikheten dras mot 50 % för att undvika överdriven säkerhet vid litet underlag.

Nästa steg mot riktig drift

  1. Koppla en marknadsdatakälla (dagliga kurser via API) i stället för demodata.
  2. Kör modellen på en server varje börsdag efter stängning.
  3. Validera med walk-forward-test innan siffror visas för användare.
  4. Paketera som app (t.ex. Capacitor eller React Native) för App Store.

Om

Valora Analytics v0.1 · demodata. Push-notiser, konto och prenumeration kommer i appversionen.

Viktigt: Siffrorna i den här versionen är simulerad demodata, inte verkliga kurser. Ingen modell kan garantera framtida avkastning, och detta är inte investeringsrådgivning. För App Store krävs tydliga friskrivningar och ofta ytterligare regelefterlevnad kring finansiella tjänster.
